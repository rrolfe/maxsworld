# Max's World

Everything Max builds lives here: https://rrolfe.github.io/maxsworld/

- `index.html` is the home page. It has the sections plus a list of everything Max made.
- `games/` is Max's Arcade. Each game gets its own folder, for example `games/pixel-wrestling/`.
- `previews/` holds the thumbnail pictures.

To add a new site, give it its own folder and add a card for it to the home page (and to the Games page if it's a game).
